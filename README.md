# Student Retention Early-Warning Dashboard
A predictive analytics project using Python and Power BI

**Status:** In progress

## Overview
A dashboard and risk model to help identify students at risk of
dropping out after their first semester. See [project brief](docs/project_brief.md).

## Tools
Python (pandas, scikit-learn), SQL, Power BI, Google Colab, GitHub

## Data
UCI "Predict Students' Dropout and Academic Success" (CC BY 4.0).
Full citation in the project brief.
